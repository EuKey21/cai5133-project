# Project Notes

## Data Setup
Download the Yelp dataset from the Yelp Open Dataset page, then unzip all files into:

- `./yelp_dataset/`

Expected files include:
- `yelp_academic_dataset_business.json`
- `yelp_academic_dataset_review.json`
- `yelp_academic_dataset_user.json`

## Notebooks (Root)
- `30D1Y_COVID.ipynb`: Runs data for year 2020 with 30 days as early window. 
- `30D1Y_PRECOVID.ipynb`: Runs data for year 2015 with 30 days as early window.
- `30D2Y_COVID.ipynb`: Runs data for year 2020 and 2021 with 30 days as early window.
- `30D2Y_PRECOVID.ipynb`: Runs data for year 2015 and 2016 with 30 days as early window.
- `30D3Y_COVID.ipynb`: Runs data for year 2020, 2021, and 2022 with 30 days as early window.
- `30D3Y_PRECOVID.ipynb`: Runs data for year 15, 2016, and 2017 with 30 days as early window.
- `60D1Y_COVID.ipynb`: Runs data for year 2020 with 60 days as early window.
- `60D1Y_PRECOVID.ipynb`: Runs data for year 2015 with 60 days as early window.
- `90D1Y_COVID.ipnyb`: Runs data for year 2020 with 90 days as early window.
- `90D1Y_PRECOVID.ipynb`: Runs data for year 2015 with 90 days as early window.
- `features_extraction.ipynb`: Extracts all the features from review, business, and user json files in the yelp academic dataset and stores them in csv files.
